MDR Engine Pro
MDR Engine Pro v2.5 is the documented vehicle simulation and AI system developed by ModWorksInteractive (MWi), covering vehicle physics, AI, police, damage, player input, pipeline, world and traffic systems.

MDR Engine Pro v2.5 — Full Module Overview

The module list below follows the MDR Engine v2.5 English documentation. Each module keeps its own documented role, designer controls, script count and script-level information instead of being compressed into five summary categories.

Recommended setup: Import the MDR Engine v2.5 folder into Assets → create an empty GameObject with MDR_SystemBootstrap → vehicle with Rigidbody, WheelColliders and MDRCarPhysicsCore → optionally add PipelineManager → Play. F3 opens Diagnostics.

The v2.5 documentation lists 164 MDR Engine scripts and recommends MDR_SystemBootstrap, MDRCarPhysicsCore, optional PipelineManager, and SurfaceSync/Bootstrap integration with MDR Road.
